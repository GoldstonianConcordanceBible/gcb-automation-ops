This is the command center for the entire GCB automation content engine.

## Golden Rules
1) Scripture stays free.
2) Agents draft-first. You approve before posting.
3) Every post gets logged (platform, link, UTM, timestamp).
4) Keep the message consistent: Mirror → Water → Fire.
5) No outrage bait. No endless debates.

## Daily flow
- Pull source content from gcb-content-factory
- Generate PACK in gcb-repurpose-packs
- Queue drafts into platform engines
- Log everything to gcb-media-map + logs
